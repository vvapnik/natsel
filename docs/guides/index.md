# Guides

Guides will appear here as the SDK, skills and Control Plane take shape:

- writing a gene by its contract;
- registering genes from CI/CD;
- running the Control Plane and the Breeder locally;
- defining a fitness function and guardrails.

!!! tip "Adding a guide"
    Put a Markdown file in `docs/guides/` and add it to `nav` in `mkdocs.yml`.
    Every push to `main` rebuilds and publishes the site.
